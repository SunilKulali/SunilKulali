### Featured projects

#### PulseData AI
[Repository](https://github.com/SunilKulali/PluseData-AI)
- **Problem:** Getting trustworthy insights from an unfamiliar dataset is slow and error-prone.
- **Approach:** Full-stack AI data intelligence tool with a dataset snapshot, automated pipeline, RAG chat over your data (GPT-4o-mini, LangChain, FAISS), join-key detection, a data health score with schema validation, and auto-clean plus dashboard generation.
- **Engineering:** Schema-agnostic KPI classification engine, plus a self-validation layer that recomputes KPIs independently and flags drift above 1%; backed by a 27-test backend regression suite.
- **Why it matters:** Shows LLM and RAG work paired with data validation, not just a chat wrapper.

`React` `FastAPI` `MySQL` `LangChain` `FAISS` `LLMs`

#### Loan Approval Prediction
[Repository](https://github.com/SunilKulali/Predictive-Analysis-of-Loan-Status-Using-Machine-Learning) · [Live app](https://loan-approval-app-9bhxipva5x7vk2rt4nz3wt.streamlit.app/)
- **Problem:** Manual loan eligibility checks are slow and inconsistent.
- **Scope:** 45,000+ records; 5 domain-specific features engineered.
- **Approach:** Compared 5 classification models, then deployed the result as a real-time Streamlit app.
- **Result:** 90.2% accuracy (model evaluation metric).
- **Why it matters:** Covers the full path from raw data to a usable prediction app.

`Python` `Scikit-learn` `Streamlit`
